# Image Watermarking Desktop App

A lightweight and efficient desktop application built with Python that allows users to easily add custom text watermarks to their images. 

## Features

- **Intuitive GUI:** Built using Python's native `Tkinter` library for a clean and responsive desktop user interface.
- **Real-Time Preview:** Instantly loads and displays a preview of the selected image within the application window.
- **Dynamic Text Watermarking:** Utilizes `Pillow` (PIL) to handle high-resolution image processing, scaling text dynamically and applying professional semi-transparent overlays.
- **Flexible Exporting:** Prompts the user to save the final watermarked output in high quality as either a `.png` or `.jpg` file.

## Tech Stack

- **Python** (Core Logic)
- **Tkinter** (Graphical User Interface & File Dialogs)
- **Pillow (PIL)** (Image Processing, Drawing & Compositing)

## Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/image-watermark-desktop-app.git](https://github.com/your-username/image-watermark-desktop-app.git)
   cd image-watermark-desktop-app

Install dependencies:
Ensure you have Python installed, then install the Pillow library:
Bash
pip install Pillow

Run the application:
Bash
python main.py

How to Use
Launch the application and click 📁 Upload Image to select an image from your computer.

Type your desired custom text into the Watermark Text input field.

Click 💾 Save Watermarked Image to choose where to export your finished image.
